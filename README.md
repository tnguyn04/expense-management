# Team Project Management 
## How to Run the Project

1. **Download ZIP** from GitHub and extract it.
2. Download and install **XAMPP** [https://www.apachefriends.org](https://www.apachefriends.org).
3. Start **Apache** and **MySQL** from the XAMPP Control Panel.
4. Copy the project folder (**expense_management**) into: `C:\xampp\htdocs\`.
5. Open **phpMyAdmin** in your browser: [http://localhost/phpmyadmin](http://localhost/phpmyadmin).
6. Create a new database named `quanlychitieu`.
7. Import the **SQL file** included in the project.
8. Open the project in your browser: [http://localhost/expense_management](http://localhost/expense_management).
